A pure-stdlib Python program that draws an invented passport spread for the fictional Republic of Talassa — a data page with a portrait, bilingual fields and a valid MRZ, and a visa page whose stamps tell one consistent travel history, including an Ostara visa that orders the holder to register with the harbourmaster within 48 hours of arrival.

## Run it

```sh
python3 main.py
```

This writes `/output/entry.png` (1024x724 PNG, under 1 MiB). No network, no third-party packages: the program rasterises the whole document itself, including its own single-stroke vector font and PNG encoder.
